## Key decisions

| Decision | Rationale | Session |
|---|---|---|
| OFF is a NEW derived vehicle status (not replacing Inactive), unlimited schedule roll-forward, OFF-unit cost from a GLOBAL System-Admin rate billed as an `Off_Unit` line, mechanic mobile list = scheduled-today + urgency-ordered, WO urgency colour pills with text (DEC-92) | OFF models "vehicle down because a WO overran its day" distinctly from the manual Inactive deactivation; it escalates Repair and sits above Blocked so a down unit is never hidden behind a lesser status, yet (unlike Inactive) still allows WO work so the overrunning WO can finish. Unlimited roll-forward keeps the schedule a pure plan (BR-13) — the overrun's only consequence is the per-day OFF-unit cost. The OFF-unit rate is a single global `app_settings` scalar to match the other billing rates (tax, markup) and because no rate is keyed by vehicle_class.
